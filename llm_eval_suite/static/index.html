Council judges

    
Judges read the results, not the raw transcript. The model under test is never a judge, because a model grading itself tends to prefer its own answers. If only one judge is available, peer ranking is skipped.

    
Suggested local defaults, if you have them in Ollama: qwen2.5:3b-instruct and llama3.2:3b. Cloud judges are off unless you type a cloud URL.
