Council judges

        
Judges read the results, not the raw transcript. The model under test is never a judge, because a model grading itself tends to prefer its own answers. If only one judge is available, peer ranking is skipped.

      

      

        

          
One or more judges use a cloud endpoint. Analysis text will leave this computer.

          

          

            
            
          

        

        

          

            

              
              
            

            

              
              
            

            

              
              
            

            
The chairman writes the final summary from the judges' reviews. The timeout is how long each judge call may take before the template summary is used. Reply length is the token cap for that call. Judge calls send think off.

          

          

            
Suggested local judges, if you have them in Ollama: phi4-mini (MIT) and granite4:micro (Apache-2.0). A judge does not grade a model from its own family. When the model under test is Phi or Granite, llama3.2:3b grades in its place. Cloud judges stay off unless you type a cloud URL.
